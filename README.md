# 💼 TaxPal – Personal Finance & Tax Estimator

TaxPal is a full-stack web application designed to help freelancers and gig workers efficiently manage their finances by tracking income and expenses, planning budgets, estimating taxes, and generating financial reports through a single, user-friendly platform.

---

## 🚀 Project Overview

The application brings multiple financial activities into a structured dashboard with a focus on simplifying day-to-day financial planning and record management.

It combines automation, organized data management, and reporting to provide a more efficient approach to handling financial information.


---

## 🎯 Problem Statement

Freelancers often face challenges in:

* Tracking income and expenses
* Managing category-wise budgets
* Estimating tax liabilities
* Maintaining organized financial records

TaxPal brings these activities together in a single platform.

## ⚙️ Installation & Setup

### Prerequisites

* Node.js
* npm
* MySQL 8.0
* Git
* Angular CLI

### Run the Project Locally

**1. Clone the repository**

```bash
git clone https://github.com/harshita582/TaxPal-Personal-Finance-Tax-Estimator.git
cd TaxPal-Personal-Finance-Tax-Estimator
```

**2. Run the frontend**

```bash
cd taxpal-frontend
npm install
npm start
```

Frontend:

```text
http://localhost:4200
```

**3. Run the backend**

Open a new terminal:

```bash
cd taxpal-backend
npm install
node src/server.js
```

Backend:

```text
http://localhost:5000
```
